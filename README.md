# Odoo 17 HMS Training

A beginner-friendly Hospital Management System (HMS) built using Odoo 17 during backend and ERP development training.

This project was developed step by step while learning the fundamentals of Odoo development including models, views, relations, menus, and security.

---

# Project Overview

The project is a simple HMS (Hospital Management System) module for Odoo 17.

It currently supports:

- Patient Management
- Department Management
- Doctors Management
- Relations between models
- Form and Tree Views
- Menus and Actions
- Access Rights and Security

The project is intentionally kept simple and beginner-friendly for learning purposes.

---

# Technologies Used

- Odoo 17
- Python
- PostgreSQL
- XML
